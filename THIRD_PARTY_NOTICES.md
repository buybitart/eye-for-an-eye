This file exists for one reason: the project's own licence says nothing about
the licences of anything you bundle *with* it. The base package has no
dependencies at all, so a plain install carries no third-party code. Every
optional extra does, and one of them is copyleft.

## The Base Package

`pyproject.toml` declares `dependencies = []`. The default wheel contains only
this project's own MIT-licensed source, and shipping it obliges you to nothing
beyond keeping the MIT notice.

## The One That Changes Your Obligations

| Package | Version | Licence | Extra |
| --- | --- | --- | --- |
| **scapy** | 2.7.0 | **GPL-2.0-only** | `capture` |

Scapy is used only for live packet capture and PCAP reading. It is not imported
by the base package, is not in the minimal wheel, and is not in the runtime
container image.

**Depending on it at runtime does not relicense this project.** Building and
distributing a *combined work* that bundles scapy (a container image, a frozen
binary, a vendored tree, a single-file installer) is a different act, and the
GPL-2.0 terms attach to that combined distribution. If you intend to ship such
an artifact, read the GPL and take your own advice; this paragraph is an
inventory note, not a legal conclusion.

If you need packet capture without that obligation, the capture helper reads
from an AF_PACKET socket and a PCAP file, and its interface is small enough to
reimplement against a permissively licensed parser.

## Data Files Are Not Dependencies

Nmap service probes, p0f signatures and MaxMind GeoIP databases are **operator
supplied and never shipped**. Their licences are separate from every package
above, and the licence of the software that reads a database is not the licence
of the database. [docs/THIRD_PARTY_DATA.md](docs/THIRD_PARTY_DATA.md) covers
each one.

Test PCAP files in this repository are synthetic. They were generated by
`dataset/generators/`, contain no captured traffic, and carry this project's
licence like the rest of the source.

## Reproducing This Table

```
python scripts/license_audit.py
```

It reads installed distribution metadata rather than a hand-kept list, so a new
dependency shows up here as a diff rather than as an omission.

## What This File Is Not

It is an inventory, checked against installed metadata on 2026-09-11. Package
metadata is sometimes imprecise (`ipwhois` says only "BSD", and `scipy` ships a
copyright header where an SPDX expression belongs), so for anything you actually
redistribute, read the licence file in the wheel rather than trusting a metadata
field, including this one.
